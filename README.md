Financial Audit Analytics Dashboard
A full-stack financial audit analytics application built with Python, Flask, SQLite, Pandas, NumPy, HTML, CSS, and JavaScript.

The project analyzes financial transactions and identifies potential audit exceptions such as duplicate transactions, high-value transactions, weekend postings, after-hours postings, and statistical outliers. It assigns each transaction a risk score and risk level and displays the results through an interactive dashboard.

Key Features
Transaction anomaly detection
Rule-based risk scoring
Interactive audit dashboard
Transaction and vendor analysis
REST APIs using Flask
SQLite database
SQL audit queries
IQR-based outlier detection
Note: The project uses synthetic financial data for educational and portfolio purposes.
